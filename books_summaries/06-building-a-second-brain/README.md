## 📌 Why this book is in the diary

This diary was already a second-brain system before it had a name. Reading Forte's framework provides three things the current structure lacks:

1. **A name for the daily skim** — *progressive summarization* explains why re-reading a note every day is cheap and useful rather than a waste.
2. **A test for folder structure** — PARA's actionability test ("will this be done by a date?") exposes why a purely subject-based tree eventually breaks.
3. **The stage that is missing** — every note here is captured and organised, but very little is *expressed* outward. That is the gap between a private archive and a second brain.

The prompt was a LinkedIn post about the diary, which asked *"does this already have a name?"* — it does, and knowing the lineage makes the system defensible in a portfolio rather than a personal hack.
