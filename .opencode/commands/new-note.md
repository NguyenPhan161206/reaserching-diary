description: Create a new research note with proper template
---
Create a new research note. Follow these steps:

1. ASK user: "Topic? Which folder? (or let me suggest based on topic)"
2. Read NOTE_TEMPLATE.md for the correct template variant based on folder
3. Determine template:
   - ai_ml/, iot_aiot/ → Template A (Tech)
   - economics_business/ → Template B (Business)
   - psychology_society/ → Template C (Social Science)
   - books_summaries/ → Template D (Book)
   - personal_evaluations/ → Template E (Evaluation)
   - Other → ASK user which template to use
4. Write full content following the template with university-level depth
5. Run depth checklist from AGENTS.md Section H (must pass all checks)
6. Add Research Journey section (AGENTS.md Section A4)
7. Add cross-references to related notes in other folders (AGENTS.md Section A6)
8. Suggest 2-3 related topics with [SUGGESTED] tag (AGENTS.md Section A3)
9. Update CONTRIBUTION_LOG.md with new entry
10. Update CONTRIBUTION_CALENDAR.md with today's activity
11. Show summary: file created, template used, suggestions made
12. Ask: "Ready to finalize? Check content before I save."

File naming: XX-descriptive-name.md (XX = next number in folder)
