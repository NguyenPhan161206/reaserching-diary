# IELTS Training

> Dedicated workspace for IELTS preparation — listening, reading, writing, speaking.
> Only questions, exercises, and answers are stored (no full transcripts).

## Purpose

Systematic IELTS practice using real-world content (YouTube interviews, podcasts, articles) as source material. Each exercise file includes:

- IELTS-format questions (easy → hard)
- Answer key with explanations
- Vocabulary extracted from source material
- Glossary for domain-specific terms

## How to Use

1. **Find an exercise file** in the skill sub-folder (e.g., `listening/`)
2. **Watch/read the source material** (link provided at top of file)
3. **Attempt all questions** before checking answers
4. **Review vocabulary list** and note new collocations
5. **Self-assess** using the band score provided

## Folder Structure

```
ielts_training/
├── README.md              ← This file
└── listening/             ← Listening practice (YouTube, podcasts)
    └── XX-source-name.md  ← Exercise files (chronological)
```

> `reading/`, `writing/`, `speaking/` — reserved for future expansion.

## Naming Convention

- Files: `XX-descriptive-name.md` (01, 02, 03...)
- Source name: slug of YouTube/video title
- Example: `01-jensen-huang-nvidia-interview.md`
